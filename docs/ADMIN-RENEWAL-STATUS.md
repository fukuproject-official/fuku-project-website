# 管理画面リニューアル：実装・検証状況

2026-10-08。GitHub mainの取得済みアーカイブを元に別ディレクトリで実装。本番は未変更。

## 今回実装した範囲

- 固定メニュー、コンパクトな2列編集、スマホ用折りたたみメニュー。
- ダッシュボードからLIVE・写真・メンバー・TOPへ移動。
- TOP内にABOUT／OUR MIND／YouTube／並び順の切り替え。案内文は折りたたみ。
- メンバー・アルバムの写真付き一覧。開いた1件だけを編集。
- 写真クリックで変更、画像上のドラッグで表示位置調整。既存3:4切り抜きも維持。
- メンバーとアルバム内写真のドラッグ並べ替え、上下／前後ボタンも維持。
- 入力後の下書き自動保存。変更中の保存を直列化し、通信中の追加入力も続けて保存。
- 保存失敗時は未保存状態を保持し、手動再試行と下書きファイル出力を用意。
- 右側の簡易プレビューを開閉。公開サイトの正確な見え方は既存の全画面プレビューを利用。
- 公開確認と保存版の照合を維持。写真処理中は公開しない。
- 画像入力は30MBまで受け付け、既存の長辺2400pxへの変換でアップロードを軽量化。
