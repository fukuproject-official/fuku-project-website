# 管理画面の使い方

公開URLの末尾に `/admin/` を付けて開きます。福プロ用の管理者メールと、既存Supabase Authのパスワードでログインしてください。Supabaseダッシュボードへのログインとは別のアカウントです。

1. 左のメニューで編集する項目を選びます。
2. 写真はファイルを選ぶかドロップ。JPEG / PNG / WebP、8MB以内。長辺2400pxに調整し、写真のメタデータを除きます。「写真の表示位置」で切り取り位置を調整します。
3. SNSはURLを貼り付けます。YouTubeは通常の動画・共有・ShortsのURLに対応します。投稿の自動取得ではありません。
4. メンバーは人数を増減でき、表示のオン・オフ、順序、今後の活動を編集できます。追加時は非表示です。
5. 下書き保存 → プレビュー → 公開する → 確認、でサイトへ反映します。サイトを再読み込みすると新しい内容になります。

下書きの文章は管理者だけが閲覧できます。ただしアップロードした写真は公開URLになるので、未解禁の写真は公開する時点でアップロードしてください。

ログイン状態は画面を閉じる・再読み込みすると終了します。長時間の編集ではこまめに下書き保存してください。保存失敗時は「保存済み」にはなりません。同時に別の画面で保存された場合、上書きを防止します。変更を控えて再ログインしてから編集を再開してください。

「見出し・ボタン・その他の文字」でメニューや静的な補足文を編集できます。プロフィール本文などはそれぞれの項目から編集します。システムのエラー案内やアクセシビリティ用ラベルは実装側で管理します。

問い合わせはメールアプリ起動または外部フォームへのリンクです。問い合わせ受信サーバー、Stripe決済、QR発券はこの管理画面には含めていません。

## 2026-09 更新

編集欄は公開ページのエリア別です。「見出し1（英語）」「見出し2（日本語）」など、実際の表示場所を表す名前から編集します。旧「見出し・ボタン・その他の文字」「プロフィール・準備中の案内」は各エリアに統合しました。

- メンバーのSNSはURLを入力したサービスだけアイコン表示します。Xと今後の活動欄は表示しません。
- メンバー写真を選ぶと3:4のトリミング画面が開きます。拡大・左右・上下を調整して決定してください。写真は600×800pxで切り出されます。
- GALLERYは「LIVEアルバム」を追加し、タイトル・日付・写真を登録します。公開側ではタイトルを押すと写真が開きます。旧サンプル写真は表示しません。
- TOP動画はHTTPSのMP4/WebMの直接URLを指定します（YouTube URLではありません）。未設定なら写真です。動画アップロード機能は含みません。自動再生できない環境ではカバー写真が表示され、再生・停止ボタンも利用できます。
- NEXT LIVEにフライヤー等の写真を追加できます。
- 下書き保存 → プレビュー → 公開する、という手順は共通です。
